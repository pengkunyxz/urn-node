# urn-node

Auto-redraws a clean US residential exit on URnetwork (free tier) every 4h.

- `urn-draw` workflow: draw -> verify (double-false + geo + stability) -> publish to Pages
- Pages artifacts: status page (no secrets), v2rayN link + sing-box subscription under a random path
- Tokens rotate on every successful redraw; old URLs die with their proxies
